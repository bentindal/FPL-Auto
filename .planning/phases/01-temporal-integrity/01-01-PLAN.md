  <name>Task 2: Fix model.py lookahead violation (TI-01: exclude current GW from training)</name>
  <files>model.py</files>
  <action>
Correct the model training loop in model.py line 58 to exclude the current gameweek from training data.

BEFORE (line 58):
```python
training_data, test_data = vastaav.get_training_data_all(season, i - training_prev_weeks, i)
```

AFTER (line 58):
```python
training_data, test_data = vastaav.get_training_data_all(season, i - training_prev_weeks - 1, i - 1)
```

Why: Currently trains on GW(i-19) through GW(i) inclusive to predict GW(i). This includes actual points from GW(i), which is lookahead bias. The corrected version trains on GW(i-20) through GW(i-1), excluding the GW being predicted.

Impact: Models will be trained on strictly historical data. This may reduce accuracy on test data momentarily (less training signal) but prevents unfair advantage from knowing the outcome you're predicting.

Verification: Ensure the change compiles and the model.py script still runs without errors. The task does NOT retrain models yet (that's Phase 3 with TimeSeriesSplit); this only fixes the boundary logic.
