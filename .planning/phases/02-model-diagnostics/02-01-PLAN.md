2. For **top 100 average squad**:
   - Group by season, aggregate to squad level (15 players)
   - Compute:
     - **Total squad xP**: sum of xP across all 15 players
     - **Squad variance**: std dev of player xP values
     - **Total squad cost**: sum of player prices
     - **ROI**: total xP / total cost (xP per £1M)
     - **Per-position totals**: GK_xp, DEF_xp, MID_xp, FWD_xp (sum by position)
     - **Sharpe ratio**: if actual points available, compute (return - risk_free) / volatility
     - **Sortino ratio**: similar to Sharpe but only downside volatility
