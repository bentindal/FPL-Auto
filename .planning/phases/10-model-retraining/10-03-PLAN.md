<task type="auto">
  <name>Task 3: Add metrics monitoring and alerting</name>
  <files>fpl_auto/retrainer.py</files>
  <action>
Create ModelMonitor class for post-retrain metrics evaluation and alerting.

Implementation:
- Class ModelMonitor with:
  - __init__() with metric baselines (RMSE, MAE, R², Spearman correlation per position from historical)
  
  - evaluate_week(gw: int, predictions: dict, actuals: dict) → dict:
    - For each position in ['GK', 'DEF', 'MID', 'FWD']:
      - Compute RMSE = sqrt(mean((pred - actual)^2))
      - Compute MAE = mean(abs(pred - actual))
      - Compute R² = 1 - SS_res/SS_tot
      - Compute Spearman rank correlation
      - Store in metrics[position] = {rmse, mae, r2, spearman}
    - Check thresholds:
      - If RMSE > baseline[position] × 1.15 → alert "RMSE degradation"
      - If MAE > 0.8 → alert "MAE threshold"
      - If R² < 0.80 → alert "Low R²"
      - If Spearman < 0.85 → alert "Ranking quality degraded"
    - Log all alerts
    - Return metrics dict
  
  - get_stability_metric(cv_scores: list) → float:
    - Returns 1 - (std / mean) of CV scores
    - Used to determine if retraining frequency should increase

Metrics thresholds per 10-CONTEXT.md:
  - RMSE: >15% above baseline triggers drift
  - MAE: >0.8 pts/player is alert threshold
  - R²: <0.80 indicates drift
  - Spearman: <0.85 suggests ranking quality loss (critical for captain selection)
  </action>
