<task type="auto">
  <name>Task 2: Implement PELT-based drift detection</name>
  <files>fpl_auto/retrainer.py</files>
  <action>
Add _detect_drift() and _get_baseline_rmse() methods to FPLModelRetrainer.

Implementation:
- Method _detect_drift(current_gw: int) → bool:
  - If current_gw < 4, return False (not enough history)
  - Fetch recent predictions for GW[current_gw-4:current_gw] from model_cache or cached predictions file
  - Fetch actuals from accumulated_gw.csv for same range
  - For each position:
    - Compute RMSE = sqrt(mean((pred - actual)^2))
    - Get baseline_rmse for position
    - If RMSE > baseline_rmse * 1.15:
      - Log f"Drift in {position}: RMSE {rmse:.3f} vs baseline {baseline_rmse:.3f}"
      - Increment drift_count[position]
    - If drift_count[position] >= 2 (2+ GWs), return True
  - Return False if no position shows persistent drift

- Method _get_baseline_rmse(position: str) → float:
  - Stored in __init__ from historical training (2019-2023)
  - Return precomputed value from dict baseline_rmse[position]

For Phase 10, PELT algorithm implementation optional; defer detailed change-point detection to Phase 10.5+. Basic rolling 4-GW RMSE monitor sufficient for launch.
  </action>
