## xP Data Sources (Temporal Safety)

From team.py data structures:
- self._xp_dicts: {pos → {player_name → single_gw_xp}}
  - Contains GW(i) predictions only
  - Safe for substitution decisions (made before GW(i) deadline)
  - Use THIS for predictive_swap logic
  
- self._all_xp_dicts: {pos → {player_name → multi_gw_discounted_xp}}
  - Contains multi-GW lookahead (GW(i), GW(i+1), etc.)
  - FORBIDDEN for substitution decisions (lookahead bias)
  - Only use for transfer/captain (decisions that plan ahead)

## Substitution Swap Position-by-Position Logic

For each position (GK, DEF, MID, FWD):
1. Identify current starter in position (from self._all_xi_players())
2. Get starter_xp from _xp_dicts[position]
3. Find all bench players in this position
4. For each bench player:
   - Calculate xP improvement: (bench_xp - starter_xp) / max(starter_xp, 0.1)
   - If improvement > 0.20 AND self.gameweek > 5:
     - Mark bench player as replacement (highest improvement wins if tie)
5. If replacement found, return bench player; else return default (lowest xp in position)

## Anti-Pattern: Over-Coupled Variant Logic

Avoid: Creating separate methods for each substitution mode (suggest_subs_static, suggest_subs_predictive).
Instead: Use single method with parameter-driven branching (phase 08-01 already does this).

Benefit: Easier to test, maintain, and compare variants side-by-side.

```python
elif config.substitution_mode == 'predictive_swap':
    """
    Predictive swap: Swap starter for bench if bench has >threshold% xP advantage.
    
    Temporal safety: Uses _xp_dicts (single-GW predictions, known before deadline).
    Never reads _all_xp_dicts (multi-GW lookahead) or actual match points (retroactive).
    """
    
    subs = []
    threshold = getattr(config, 'substitution_trigger_threshold', 0.20)
    only_after_gw5 = True  # Prevent early-season churn
    
    # Process each position independently
    for position in POSITIONS:
        xi_players_in_pos = [p for p, pos in self._all_xi_players() if pos == position]
        
        if not xi_players_in_pos:
            continue  # No starter in this position (shouldn't happen with valid squad)
        
        starter = xi_players_in_pos[0]  # Primary starter (XI ordering matters)
        
        # Get starter xP from single-GW dict (temporal safety)
        starter_xp = self._xp_dicts.get(position, {}).get(starter, 0)
        
        # Find bench players in this position
        bench_players_in_pos = [
            p for p in self._pos_squad_list(position)
            if p not in [s for s, _ in self._all_xi_players()]  # Not in XI
        ]
        
        if not bench_players_in_pos:
            # No bench options; keep starter
            continue
        
        # Find best bench player by xP improvement
        best_bench = None
        best_improvement = 0
        
        for bench_player in bench_players_in_pos:
            bench_xp = self._xp_dicts.get(position, {}).get(bench_player, 0)
            
            # Calculate improvement
            improvement = (bench_xp - starter_xp) / max(starter_xp, 0.1)
            
            # Check threshold: only swap if improvement > threshold AND after GW5
            if improvement > threshold and (not only_after_gw5 or self.gameweek > 5):
                if improvement > best_improvement:
                    best_bench = bench_player
                    best_improvement = improvement
        
        # Add to subs: either swapped bench player or default lowest xP
        if best_bench:
            subs.append([best_bench, position])
        else:
            # Default: lowest xP in position
            ranked = sorted(
                [[p, self._xp_dicts.get(position, {}).get(p, 0)] for p in self._pos_squad_list(position)],
                key=lambda x: float(x[1])
            )
            if ranked:
                subs.append([ranked[0][0], position])
    
    return subs
```

**Key Design Decisions:**

1. **Threshold: 0.20 (20%)**
   - Matches Phase 6 transfer_xp_threshold for consistency
   - Conservative: requires significant advantage before swapping
   - Tunable via config.substitution_trigger_threshold

2. **Gating on GW > 5:**
   - Prevent early-season overreaction to small samples
   - Stability window: let early-season volatility settle
   - After GW5, model predictions stabilize

3. **Position-by-position processing:**
   - GK can only swap with GK bench
   - DEF with DEF, MID with MID, FWD with FWD
   - Respects position constraints (no cross-position swaps)

4. **Temporal Safety:**
   - Uses _xp_dicts[position] ONLY (single-GW predictions)
   - Comment in code: "# Temporal gate: _xp_dicts, never _all_xp_dicts"
   - Safe because: predictions generated before GW deadline, not retroactive

5. **Fallback to static:**
   - If no swap condition met, use lowest xP player (same as static mode)
   - Smooth degradation: predictive_swap can fall back to static per-position

**Error Handling:**
- If _xp_dicts missing a player: use default 0 (safe fallback)
- If bench_players_in_pos empty: skip (shouldn't happen with valid squad)
- If starter not found: skip position (defensive, shouldn't happen)

**Test Edge Cases:**
- Swap when bench has 20.1% advantage: should swap
- Swap when bench has 19.9% advantage: should NOT swap (just under threshold)
- Swap attempt when GW=3: should NOT swap (too early)
- Swap attempt when GW=6: should swap if improvement > 20% (after stability window)
