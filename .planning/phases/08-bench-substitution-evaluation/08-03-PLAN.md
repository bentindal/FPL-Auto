## Phase 5-7 Evaluation Framework (Reuse Pattern)

From Phase 5-7 execution reports, the evaluation pattern is:

1. **Walk-forward structure:**
   - Train seasons: 2021-22, 2022-23 (model training window)
   - Test seasons: 2023-24, 2024-25 (held-out validation)
   - Two distinct test iterations

2. **Metric computation (per season, per variant):**
   - total_points: Sum of all GW points across season
   - sharpe_ratio: Return / volatility (risk-adjusted return)
   - sortino_ratio: Return / downside volatility (penalizes losses more)
   - max_drawdown: Largest peak-to-trough decline
   - variance: Consistency metric (lower = more stable)

3. **CI and correction:**
   - Bootstrap: 10,000 iterations of resampling with replacement
   - 95% CI: 2.5th and 97.5th percentiles
   - Bonferroni: α = 0.05 / number_of_comparisons = 0.0125 for 4 variants
   - Non-overlapping CIs indicate statistical significance at corrected α level

```python
def _compute_comparison(results: Dict, eval_config: EvaluationConfig) -> Dict:
    """
    Compute summary comparison across all variants.
    
    Returns:
        {
            'points_by_variant': {name → (mean, ci_lower, ci_upper)},
            'bonferroni_significant': [(variant_a, variant_b, is_significant), ...],
            'recommendation': 'best_variant_name',
            'summary_table': str
        }
    """
    
    # Extract metrics by variant
    metrics_by_variant = {}
    for variant_name, result in results.items():
        if 'error' in result:
            continue
        
        # Get combined metrics (across both test seasons)
        combined = result.get('combined_metrics', {})
        metrics_by_variant[variant_name] = {
            'points': combined.get('total_points', 0),
            'sharpe': combined.get('sharpe_ratio', 0),
            'sortino': combined.get('sortino_ratio', 0),
            'ci_lower': combined.get('total_points_ci_lower', 0),
            'ci_upper': combined.get('total_points_ci_upper', 0),
        }
    
    # Find best variant (highest mean points)
    best_variant = max(metrics_by_variant.items(), key=lambda x: x[1]['points'])[0]
    
    # Check for non-overlapping CIs (statistical significance)
    significant_pairs = []
    variant_names = list(metrics_by_variant.keys())
    for i, v1 in enumerate(variant_names):
        for v2 in variant_names[i+1:]:
            m1, m2 = metrics_by_variant[v1], metrics_by_variant[v2]
            # Non-overlapping CIs indicate significance at Bonferroni-corrected α
            overlaps = m1['ci_lower'] <= m2['ci_upper'] and m2['ci_lower'] <= m1['ci_upper']
            significant_pairs.append((v1, v2, not overlaps))
    
    # Build summary table
    summary_lines = [
        "Variant Comparison (sorted by total points):\n",
        f"{'Variant':<40} {'Points':<10} {'Sharpe':<10} {'CI Lower':<10} {'CI Upper':<10}",
        "-" * 80,
    ]
    
    for variant_name in sorted(metrics_by_variant.keys(), key=lambda x: metrics_by_variant[x]['points'], reverse=True):
        m = metrics_by_variant[variant_name]
        summary_lines.append(
            f"{variant_name:<40} {m['points']:<10.1f} {m['sharpe']:<10.2f} {m['ci_lower']:<10.1f} {m['ci_upper']:<10.1f}"
        )
    
    summary_lines.append("")
    summary_lines.append("Bonferroni-Corrected Significance (α=0.0125 for 4 variants):")
    summary_lines.append("-" * 80)
    for v1, v2, is_sig in significant_pairs:
        sig_mark = "**" if is_sig else "  "
        summary_lines.append(f"{sig_mark} {v1} vs {v2}: {'SIGNIFICANT' if is_sig else 'NOT significant'}")
    
    summary_lines.append(f"\nRecommendation: {best_variant} (highest points)")
    
    return {
        'metrics_by_variant': metrics_by_variant,
        'significant_pairs': significant_pairs,
        'best_variant': best_variant,
        'summary_table': '\n'.join(summary_lines),
    }
```

```python
def bench_utilization_pct(team_history: Dict) -> float:
    """
    Calculate percentage of season where bench players contributed (made subs).
    
    Args:
        team_history: Dictionary with keys 'gameweek_results' containing
                     per-GW records with 'subs_made' or 'bench_players_played' info
    
    Returns:
        Float: percentage of GWs where at least one bench player was substituted in
               or played due to starter unavailability
    
    Semantics:
    - 0% = static team, no bench rotations
    - 50% = half the season used bench players
    - 100% = every GW at least one bench swap/substitution
    """
    
    if 'gameweek_results' not in team_history:
        return 0.0
    
    gw_results = team_history['gameweek_results']
    gws_with_bench_play = sum(
        1 for gw in gw_results
        if gw.get('subs_made', False) or gw.get('bench_contribution', 0) > 0
    )
    
    total_gws = len(gw_results)
    if total_gws == 0:
        return 0.0
    
    return (gws_with_bench_play / total_gws) * 100.0
```

```python
def bootstrap_ci(values: List[float], ci: float = 0.95, iterations: int = 10000) -> Tuple[float, float]:
    """
    Compute bootstrap confidence interval for given values.
    
    Args:
        values: List of metric values (e.g., points from multiple seasons)
        ci: Confidence level (default 0.95 for 95% CI)
        iterations: Bootstrap resampling iterations (default 10000)
    
    Returns:
        (ci_lower, ci_upper): Bounds of confidence interval
    """
    if len(values) == 0:
        return (0, 0)
    
    bootstrap_samples = []
    for _ in range(iterations):
        sample = np.random.choice(values, size=len(values), replace=True)
        bootstrap_samples.append(np.mean(sample))
    
    alpha = 1 - ci
    ci_lower = np.percentile(bootstrap_samples, alpha/2 * 100)
    ci_upper = np.percentile(bootstrap_samples, (1 - alpha/2) * 100)
    
    return (ci_lower, ci_upper)
```

**Verify Bonferroni correction function (from Phase 5):**

```python
def apply_bonferroni_correction(num_comparisons: int, original_alpha: float = 0.05) -> float:
    """
    Compute Bonferroni-corrected significance level.
    
    For Phase 8: 4 variants → num_comparisons = 4
    → corrected_alpha = 0.05 / 4 = 0.0125
    
    Args:
        num_comparisons: Number of variants being compared
        original_alpha: Uncorrected significance level (default 0.05)
    
    Returns:
        Bonferroni-corrected alpha level
    """
    return original_alpha / num_comparisons
```
