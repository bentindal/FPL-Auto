```python
def suggest_subs(self, strategy_config=None):
    """
    Suggest bench players based on substitution strategy mode.
    
    Args:
        strategy_config: Optional StrategyConfig with substitution_mode, substitution_trigger_threshold.
                        If None, defaults to static (backward compat).
    
    Returns:
        List of 4 subs: [[gk_name, 'GK'], [def_name, 'DEF'], [mid_name, 'MID/DEF'], [fwd_name, 'MID/FWD']]
    """
```

**Implementation (supporting both modes):**

1. **Mode: static (default, current behavior)**
   - Get all squad players with _xp_dicts (single-GW xP only)
   - For each position, identify the player with LOWEST single-GW xP
   - That player becomes the bench (gets subbed in if starter unavailable)
   - Return bench order: [GK (lowest), DEF (lowest), other (lowest), other (lowest)]
   - This is TEMPORALLY SAFE: uses only GW(i) predictions (known before deadline)

2. **Mode: predictive_swap**
   - Get all squad players with _xp_dicts (single-GW xP)
   - For each position with a starter:
     a. Find the starter's xP from _xp_dicts[pos]
     b. Find all bench players in this position
     c. For each bench player, calculate xP improvement: (bench_xp - starter_xp) / max(starter_xp, 0.1)
     d. If improvement > 20% AND gameweek > 5, mark this bench player for swap
     e. Otherwise, use default static selection
   - Return updated bench order with predictive swaps prioritized
   - This is TEMPORALLY SAFE: uses only GW(i) single-GW xP (same source as static mode)

**Key Temporal Safety Detail:**
- Use ONLY self._xp_dicts[pos] (single-GW predictions)
- NEVER read self._all_xp_dicts in substitution decisions (that's multi-GW lookahead)
- NEVER read match results or actual points (retroactive decision-making)
- Decision happens once per GW before gameweek deadline
- Include inline comment: "# Temporal gate: using _xp_dicts (GW-i predictions, safe)"

**Error handling:**
- If squad has < 4 valid subs, raise ValueError (squad construction failure upstream)
- If _xp_dicts is missing a player, use default xP of 0

**Backward compatibility:**
- If strategy_config is None, use static mode (existing behavior)
- auto_subs() will call with self.strategy_config (pass through)
- Existing tests unaffected

class TestTeamSubstitution(unittest.TestCase):
    """Test suggest_subs() with both substitution modes (static, predictive_swap)."""
    
    def setUp(self):
        """Create test team with known xP distribution."""
        self.season = '2021-22'
        self.gw = 1
        self.team = Team(
            season=self.season,
            gameweek=self.gw,
            strategy_config=BENCH_SAFE  # Default
        )
    
    def test_suggest_subs_static_mode(self):
        """Static mode should return lowest xP players as bench."""
        config = BENCH_SAFE  # substitution_mode='static'
        subs = self.team.suggest_subs(strategy_config=config)
        
        # Verify 4 subs returned
        self.assertEqual(len(subs), 4)
        
        # Verify format: [[name, pos], ...]
        self.assertEqual(subs[0][1], 'GK')  # First is always GK
        
        # Verify subs are not in starting XI
        xi_names = [p[0] for p in self.team._all_xi_players()]
        for sub in subs:
            self.assertNotIn(sub[0], xi_names)
    
    def test_suggest_subs_predictive_swap_mode(self):
        """Predictive swap should trigger if bench has >20% xP advantage."""
        config = BENCH_SPECULATIVE
        config.substitution_mode = 'predictive_swap'
        config.substitution_trigger_threshold = 0.20
        
        subs = self.team.suggest_subs(strategy_config=config)
        
        # Verify 4 subs returned
        self.assertEqual(len(subs), 4)
        
        # Verify format is correct
        self.assertEqual(subs[0][1], 'GK')
    
    def test_auto_subs_with_strategy_config(self):
        """auto_subs() should use passed strategy_config."""
        config = BENCH_SAFE
